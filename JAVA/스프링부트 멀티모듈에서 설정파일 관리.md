# 멀티모듈의 설정파일 관리

기본적으로 스프링 부트는 실행되는 모듈의 classpath에서만 application.yml을 찾는다
즉, 최상위 모듈이 존재하고 이것이 실행 모듈이라면 하위 모듈의 application.yml은 자동으로 인식되지 않는다

해결 방법
1. 설정을 최상위 모듈의 application.yml으로 이동

2. 설정 클래스를 통해 해결
하위 모듈에서 @ConfigurationProperties를 사용하여 설정을 관리하고
상위 모듈에서 활성화

```java
// module-common의 JwtProperties
@ConfigurationProperties(prefix = "jwt")
@Data
public class JwtProperties {
    private String secret;
    private long expiration;
}

// module-api의 설정
@Configuration
@EnableConfigurationProperties(JwtProperties.class)
public class JwtConfig {
    // JWT 관련 빈 설정
}
```
